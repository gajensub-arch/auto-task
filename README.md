# Auto Task Planner

A lightweight, offline-first task board that runs entirely in the browser. Capture new work, prioritise with colour-coded badges, edit inline, and store everything locally without a backend.

## Features

- 📝 Create tasks with a title, description, due date, and priority level
- ✅ Toggle completion directly from a task card
- ✏️ Edit existing tasks in a focused dialog
- 🗑 Delete tasks you no longer need
- 🎯 Filter between all, open, and completed tasks
- 💾 Data persists automatically in `localStorage`

## Getting started

Open `index.html` in any modern browser. No additional build step or server is required.

## Development notes

- Styles and scripts live alongside the HTML for simple hosting.
- The design is dark-theme friendly and adapts to smaller screens.
- Tasks are sorted by priority and creation time for quick triage.
